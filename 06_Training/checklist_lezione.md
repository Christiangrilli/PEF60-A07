# Checklist – Lezione simulata

## Prima della presentazione

- [ ] Ho identificato classe e contesto.
- [ ] Ho esplicitato i prerequisiti.
- [ ] Ho definito obiettivi chiari e verificabili.
- [ ] Ho distinto, quando necessario, conoscenze, abilità e competenze.
- [ ] Le attività sono coerenti con gli obiettivi.
- [ ] La metodologia è motivata in rapporto al compito.
- [ ] Ho previsto strategie inclusive e di personalizzazione.
- [ ] Ho indicato tempi e materiali.
- [ ] Ho previsto una verifica coerente.
- [ ] Ho definito criteri/evidenze per la valutazione.
- [ ] Ho individuato eventuali competenze chiave mobilitate.
- [ ] So spiegare perché ogni scelta didattica è stata fatta.

## Durante la presentazione

- [ ] Non mi limito a esporre contenuti: descrivo una situazione di apprendimento.
- [ ] Rendo chiaro che cosa fanno gli studenti.
- [ ] Mantengo il filo logico tra obiettivi, attività e valutazione.
- [ ] Considero tempi e gestione della classe.
- [ ] Uso il digitale solo se ha una funzione didattica precisa.

## Dopo la presentazione

- [ ] So indicare come raccoglierei le evidenze dell'apprendimento.
- [ ] So spiegare come adatterei la lezione a differenti bisogni/livelli di partenza.
- [ ] So indicare una possibile criticità e una soluzione.
- [ ] So spiegare come utilizzerei il feedback.
- [ ] So riflettere su come migliorerei la proposta dopo aver osservato gli esiti.
